1️⃣ 升级 & 胜负

  • 头游+二游（双下）→ 升3级
  • 头游+三游 → 升2级
  • 头游+末游 → 升1级
  • 先打过A者胜 · 双下才是真赢，头游是及格

2️⃣ 残局金口诀（对手剩牌→打法）

对手剩牌 你出
10张 出对子（十张打一双）
9张 出单张（九张打一张）
7-8张 出顺子/三带二（夯）；7张要炸，8张不急炸
6张 必须开炸（剩六开炸没商量）
5张 出对子（炸五不炸四）
4张 慎炸（枪不打四）
3张 出能回收的对子/单，不打三不带
2张 拆小对打单张，杜绝出对子

3️⃣ 核心口诀

  • 有王打一张，无王打一夯
  • 情况不明，对子先行
  • 炸打第一顺，后发制人
  • 两个小单张，不打不健康
  • 顺子打到头，对手没想头
  • 炸七不炸八，该炸还要炸

4️⃣ 用炸法则（三炸三不炸）

✅ 炸：关键晋级牌 / 威胁队友头游的冲锋牌 / 绝地翻盘终结牌 ❌ 不炸：试探性出牌 / 可压制小牌 / 无支援孤弹

5️⃣ 记牌精简

只记：4张王 + 8张级牌(含红桃配) + 8张A + 8张K + 5和10 - 5/10各出3张以上 → 无顺子 - 自己断门且全场未出 → 该点成炸概率极高

6️⃣ 配合铁律

  • 顶上家，吊下家
  • 谁打谁收，不轻易接对家牌
  • 传牌必接（机会只有一次）
  • 宁可自己末游，送队友头游

7️⃣ 逢人配（百搭）用法

  • 首选配4头炸，次选同花顺
  • 只配中小牌，不配大牌
  • 百搭单走=白搭（投降式）

8️⃣ 忌讳（新手五忌）

见牌就压 / 拆整牌 / 该炸不炸 / 目中无队友 / 残局全是小单张

9️⃣ 十六字真经

保牌型，少拆牌；帮队友，留炸弹；记大牌，算剩牌；先双下，后第一。

🔟 心态

掼蛋拼人强不拼牌强。好牌只是入场券。 该忍就忍，该认怂就认怂；赢1分好过输3分。

第一部分·基础规则与牌型

基本配置

  • 2副扑克 108张，4人，对面2人为队友，每人27张
  • 逆时针出牌
  • 从2打到A，先打过A者胜

牌点大小（从大到小）

大王 ＞ 小王 ＞ 级牌(当前打法，该点数即级牌) ＞ A ＞ K ＞ Q ＞ J ＞ 10 ＞ 9 ＞ 8 ＞ 7 ＞ 6 ＞ 5 ＞ 4 ＞ 3 ＞ 2

牌型列表

牌型 说明
单张 任一张
对子 两张同点数
三张 三张同点（三不带）
三带二 三张+一对（夯）
顺子 5张连续单牌
连对 3对连续对子
钢板 2个连续三张
炸弹 ≥4张同数值
同花顺 同花5张连续（最强炸形态之一）
天王炸 4张王（最大）

炸弹大小排序

天王炸 ＞ 六张及以上炸 ＞ 同花顺 ＞ 五张炸 ＞ 四张炸

升级机制

名次 升级
头游+二游（双下） 升3级
头游+三游 升2级
头游+末游 升1级

关键特殊规则

  • 报牌：剩余≤10张须明示牌数
  • 接风：上游出完无人压，搭档获下圈领出权
  • 逢人配（百搭）：当前级牌的红桃牌，可替代除王外任意牌

第二部分·开局准备（抓牌/插牌/理牌）

抓牌（牌序即思路）

  • 边抓边排：大王→小王→级牌→主牌→A→K→... 降序
  • 大小鬼钉最左，百搭放最右
  • 好处：牌型一目了然、快速判牌力、不给对手读牌时间

插牌（同花早当家）

  • 同点、同花主动凑一起，预判组合能力
  • 炸弹/同花顺是"插"出来的

理牌（定方向判角色）

三件事：数炸弹（火力评估）、找缺陷（短板排查）、定角色（主攻/辅助）

判断标准：＞3个完整套路+≥2个炸弹兜底 → 可争头游；凑不出2个套路 → 当辅助

第三部分·牌力评估与角色定位

先看牌型，后定角色

摸牌先整型（顺子/钢板/三连对/单张冗余），再判断主攻还是辅助。

定位比牌力更重要。牌差则不争头，把队友送走就是胜利。拿烂牌还当英雄＝最快双下制造机。

手牌结构判断

  • 组牌偏好：优先组顺子和对子（强势牌型），减少单张和三带二（弱势牌型）
  • 健康标准：单张≤2张才健康，多余单张优先拆小对补齐
  • 火力评估：炸弹数量+能否配同花顺+百搭用法

主攻 vs 辅助判断

手牌特征 角色
多炸弹、多大牌、牌型整 主攻（主动冲牌控节奏）
散牌多、无炸弹、大牌少 辅助（配合队友、卡对手）

第四部分·出牌策略

核心出牌准则

  1. 有王打一张，无王打一夯
  2. 手握大小王→首轮出单张试探，用王回收牌权
  3. 无王→出三带二快速减手牌
  4. 情况不明，对子先行：中局出中等对子（10、J）试探各家牌力
  5. 两个小单张，不打不健康：尽早清小单，防残局被卡
  6. 轻易不打三带二，要打就要能打光：拆散对子/顺子会增加出牌轮次
  7. 顺子打到头，对手没想头：出最大顺子（10JQKA），逼对手用炸
  8. 先小后大，有序出牌：按从小到大出，大牌留后手控制

谁打谁收（牌权控制）

  • 每一次主动出牌，确保有大牌能接回牌权
  • 出牌前先想三步：队友接不接、对手谁能管、下轮牌权在谁手
  • 牌权定生死

领出策略

  • 优先出第二小的牌：卡住下家，迫使对手耗费上手机会，为后期配合对家预留小牌
  • 尽量不长留小牌过多（卡手）
  • 理想状态：仅留一手下家想顺的小牌

第五部分·团队配合

核心原则：2v2配合 > 单打独斗

掼蛋是双人团队游戏，宁可自己末游也要送队友头游。

配合铁律

原则 说明
主攻/助攻分工 牌强抢头游，牌弱当辅助
谁打谁收 对家发牌优先不接
传牌必接 队友传牌必接（机会可能只有一次）
顶牌护家 下家出牌用大牌精准压制小牌
借风利用 搭档将清空时保留关键牌等借风

顶上家，吊下家（位置风水）

  • 顶住上家：上家出什么只要能管上就别客气；上家甩炸你敢硬碰硬
  • 吊住下家：永远不轻易喂小牌给下家"顺"走；不按牌面大小排，按"敌我需求"排

送牌技巧

  • 送牌由大到小：先送中高对子诱导对手耗大牌/炸弹，再放小牌
  • 对家缺单给单、缺对给对、摸不准给顺子
  • 危险牌转移：中小级牌尽早传给对家助其组炸；断门花色小牌立刻脱手

角色切换

  • 牌强主动进攻清理牌型；牌弱配合对家助其走牌
  • 根据局势灵活切换主攻/助攻

第六部分·记牌与读牌

记牌五层次（从新手到超一流）

层次 记忆范围
新手 4张王 + 6张主牌
初级 + 2张红桃配 + 8张A
高级 + 所有花牌（K/Q/J/10）
一流 + 动态信息（各家第一手、开炸后出牌）
超一流 整局复盘倒推，现实再现

精简记牌法（实战够用）

必记核心：4张王、8张级牌（含红桃配）、8张A+8张K、5和10

记牌优先级：先记断张（哪些点数出完）→ 再记关键大牌 → 最后记对手牌型倾向

口诀：记大不记小、记断不记全

关键牌监控

  • 5和10是组顺子骨架：5/10各出3张以上 → 对手无顺子（含这些点数的）
  • 断张判断：自己无某张且全场未出 → 该牌成炸概率极高，重点防范
  • 主牌监控：打10时若场上已出3张10，必有人藏主牌炸弹

读牌技巧（看对手）

现象 判断
频繁出对子 缺顺子
首出顺子 大概率有回手牌
连续出单张 手握炸弹/大牌，想抢牌权
出牌犹豫 牌型适配差（可针对压）
快速出牌 牌型整齐（需谨慎）
思考过久后出牌 可能精心配的同花顺/高阶炸
第一轮不要第二轮突然大牌接 做了拆牌重组
对手拆牌管你（拆对拆顺） 暴露弱点，后续专攻其拆掉的牌型

察张·控张·算张（记牌心法）

  • 察张：观察组合牌（三带二/连对/钢板）出牌张数与牌路，跳出只盯大牌的局限
  • 控张：把控自身出牌张数节奏，不乱拆乱打核心组合，保留调整空间
  • 算张：依前期观察推算全场剩余牌量、潜在炸弹、关键级牌分布

第七部分·炸弹的使用艺术

核心法则："3不炸"

  1. 不炸无关小牌
  2. 不炸队友能接的牌
  3. 不炸必输之局

"三炸三不炸"铁律

必炸： - 炸对手关键晋级牌 - 炸威胁搭档头游的冲锋牌 - 炸己方绝地翻盘的终结牌

不炸： - 试探性出牌 - 可压制的小牌型 - 后段无支援的孤弹

该炸的三种情况

  1. 对手冲刺通关
  2. 对手大牌控场压节奏
  3. 队友需要解围夺权

用炸层次

炸弹 用法
小炸 抢牌权、逼对手大炸、破顺逼炸
中炸 控场保队友
大炸/同花顺 留到最后封头、保头游、绝杀

时机口诀

  • 炸七不炸八（对手7张关键要炸，8张谨慎）
  • 炸五不炸四（对手5张可炸，4张谨慎——"枪不打四"）
  • 打七不打八（出三带二试探逼炸）
  • 小炸及时用，大炸留残局
  • 烂在手里的炸等于没有

炸弹战法

  • 一炸保两单：组炸与顺牌冲突时，不余两张以上单牌且有先发权可组炸
  • 炸牌无大小：小火也能立大功，能"断对手路"即可
  • 诱炸计 / 拆弹术 / 威慑力：用对K诱对10炸再对A反杀；用单张小主牌逼对手拆炸弹对子
  • "四张牌陷阱"：对手剩4张可能是散牌/两对/三带一/炸弹本身，贸然炸易浪费

第八部分·残局决胜

按对手剩牌数精准应对（核心表）

对手剩牌 推测牌型 应对策略
2张 对子或单张 拆小对打单张，杜绝出对子；出"三张"物理阻断回手
3张 对子+单/三不带/炸弹 出能回收的对子/单张，不打三不带
4张 炸弹/两对/三带一 慎炸（"枪不打四"）；无炸确认可出单试探
5张 顺子或三带二 优先出对子破坏顺子结构；炸五不炸四
6张 多牌型 必须开火（"剩六开炸没商量"）
7张 炸弹+单手牌 开炸成功率高；出三带二试探
8张 两手整齐独立牌型 不贸然开炸
9张 — 出单张（"九张打一张"）
10张 — 出对子（"十张打一双"）

自身残局原则

  • 10张内整牌减手数，不留散牌
  • 优先留单牌、对子（百搭牌型），少留顺子/连对
  • 越到最后越保守，等对手暴露牌型再精准卡点
  • 理想形态：顺子→对子→控制牌
  • 小单张是残局毒药：开局清小单，中局稳节奏，残局只留A、2、王

登基收尾

  • 逼炸为先：先用小牌逼出对手所有炸弹，再出关键牌型，避免登基牌被炸拦截
  • 登基收尾：剩最后1-2手时用红心配凑登基牌（顺子/三带二），确保无人能压直接清场

冲刺技巧

  • 剩两手牌且一手是炸弹 → 拥有"强制出牌权"，另一手打出后立刻用炸断对手后路
  • 对手≤6张且无力应对时突袭最佳
  • 炸弹要炸到"能威胁头游"的人，而非最后随便炸

保二游

  • 自己无法争头游 → 果断用牌/炸弹帮搭档挡牌，杜绝双下，守住团队分

第九部分·心理博弈

虚实结合

  • 强牌弱打，弱牌强打：牌强示弱诱敌，牌弱装强势干扰判断
  • 多打心理战，多放烟雾弹：控制出牌节奏（停顿/犹豫）误导对手
  • 有炸弹时故意犹豫，让对手误判而放松警惕

多样化打法

  • 快慢变速：牌整优势快节奏（不给对手思考）；牌散局势复杂慢节奏（增压力）；突然切换打乱预判
  • 逆风破局：牌型弱时故意出非常规牌型（乱出顺子/拆炸弹）制造混乱，为搭档创造机会

误导技巧

  • 故意拆散关键牌让对手误判你无顺子
  • 用连续小炸弹迷惑对手，实则保留大炸收尾

第十部分·贡还牌博弈

进贡原则

  • 留强弃弱：只送最小闲置单张，保留炸弹/大牌/级牌/百搭，不拆对子/成型牌组
  • 贡牌花色博弈：给对手贡相邻花色多的级牌（打断其凑同花顺）；给队友反之（帮补花色缺口）

还牌原则

给队友：还小不还大、还5/7优先、拆二不拆三，优先送单张助其组炸 给对手：还大不还小、不送5/7、拆三不拆二，送大牌让其留单张

还牌禁忌

  • 避免送2/3等边张（易凑大牌）
  • 绝不给对手送"差1张就成炸"的牌，哪怕拆自己牌型
  • 给队友还牌优先凑炸、补缺，其次凑对子

双贡送同牌

双贡时两家给对手送相同牌，抵消其选牌优势

第十一部分·常见误区与忌讳

新手五忌（自查）

  1. 见牌就压
  2. 拆整牌争一手
  3. 该炸不炸
  4. 目中无队友
  5. 残局全是小单张

三条以上仍在门外。

其他大忌

  • 盲目出炸：前期随意用炸，导致后期无牌可守
  • 忽略断张：未统计关键牌缺失，错判对手炸风险
  • 过度保守：残局不敢出炸，被对手小牌溜走
  • 忽视对家需求：不观察对家出牌意图，配合失误
  • 整牌轻易拆：为压一手单张拆顺子，最后剩4、7、9、Q（新手破产路径）
  • 单张拖到残局：小单张是残局毒药

心态铁律

  • 该认怂就认怂：菜鸟硬撑硬炸一把输到双下；高手牌不好目标立刻调为"保平争胜"
  • 双下是真赢，头游是及格：一家走不算赢，两家走才叫胜
  • 忍字当头，权不乱用：有权不乱用，有炸不乱炸
  • 赢1分好过输3分

第十二部分·进阶心法与口诀大全

十六字真经（必背）

保牌型，少拆牌；帮队友，留炸弹；记大牌，算剩牌；先双下，后第一。

精选口诀汇总

残局：
  对手剩五张，出牌出两张
  对手剩六张，尽量不打双（或：剩六开炸没商量）
  七张八张，正常出夯
  九张打一张，十张打两张
  炸七不炸八，该炸还要炸
  枪不打四，炸五不炸四
出牌：
  有鬼打一张，无鬼打一夯
  情况不明，对子先行
  两个小单张，不打不健康
  顺子打到头，对手没想头
  炸打第一顺，后发制人
配合：
  掼蛋要配合，不挡对家路
  对家要啥就给啥，拼尽全力也送上
  有打有收，不轻易接对家牌
  顶牌为了对家要，目的不让下家套
  顶上家，吊下家
心理：
  强牌弱打，弱牌强打
  多打心理战，多放烟雾弹
  先下家，后上家；先配合，后单打

越阶核心心法

  1. 先看牌型，后定角色——定位比牌力更重要
  2. 炸弹是资源不是面子——不炸价值决定
  3. 整牌如山不可轻拆——完整牌型远比临场压制值钱
  4. 单张早清大牌留后——小单是残局毒药
  5. 队友优先忌抢一路——送出去的总会回来
  6. 看三步打一手——牌权定生死，谁打谁来收
  7. 双下是真赢头游是及格——算团队总账
  8. 忍字当头权不乱用——不该出时不出

世界观

掼蛋拼的是人强不是牌强。好牌只是入场券。 记算、配合、控炸、博弈四大维度融合，才是从新手到顶尖的完整路径。 2026年是掼蛋国际化元年，玩家已破1.4亿，首届掼牌世界杯12月在希腊奥林匹亚开打。
